# Como contribuir

## Antes de desenvolver

1. Escolha uma tarefa pequena e bem definida.
2. Confirme se ninguém está trabalhando nos mesmos arquivos.
3. Atualize a `main` e crie uma branch própria.

## Padrão de branches

- `front/nome-da-tarefa`
- `back/nome-da-tarefa`
- `fix/nome-do-problema`
- `docs/nome-da-alteracao`

## Padrão de commits

- `feat(front): adiciona formulário de perfil`
- `feat(back): cria endpoint de competências`
- `fix(front): corrige validação de e-mail`
- `docs: atualiza contrato da API`

## Checklist do Pull Request

- [ ] Minha branch foi atualizada com a `main`.
- [ ] Alterei apenas arquivos relacionados à tarefa.
- [ ] Testei o fluxo alterado.
- [ ] Não incluí senhas, tokens ou arquivos `.env`.
- [ ] Expliquei o que mudou e como testar.
- [ ] Solicitei a revisão da outra integrante.

## Modelo de descrição

```text
O que foi feito:
-

Como testar:
1.

Capturas de tela (quando houver):
-

Observações:
-
```
